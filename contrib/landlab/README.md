# Landlab coupling

To couple ASPECT with the surface evolution code [Landlab](https://landlab.csdms.io/), installation
can be done using [uv](https://docs.astral.sh/uv/) as follows:
```
uv sync --project contrib/landlab/
source ./contrib/landlab/.venv/bin/activate
```

See the [Manual section on Landlab](https://aspect-documentation.readthedocs.io/en/latest/user/install/local-installation/aspect-with-dependencies/index.html#landlab) for more information.
